# Fengkx Tap

## How do I install these formulae?

`brew install fengkx/tap/<formula>`

Or `brew tap fengkx/tap` and then `brew install <formula>`.

## WeRead agent skill

Install the CLI with `brew install fengkx/tap/weread`. Existing users can run
`brew upgrade fengkx/tap/weread`. Give your agent the [WeRead skill](skills/weread/SKILL.md)
or use the installed copy at `$(brew --prefix weread)/share/weread/skills/weread/SKILL.md`.

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
